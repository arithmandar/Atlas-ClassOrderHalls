# Atlas Class Order Halls

Class order hall maps for the World of Warcraft Atlas addon.

Atlas Class Order Halls is an optional Atlas plugin that provides maps of
Legion class order halls. It requires the Atlas core addon and does not run
as a standalone addon.

## Downloads

- [Atlas Class Order Halls on CurseForge](https://www.curseforge.com/wow/addons/atlas-classorderhalls)
- [Atlas core addon on CurseForge](https://www.curseforge.com/wow/addons/atlas)

Choose releases compatible with your WoW client. Map coverage and available
information may vary by release.

## Installation

1. Install the Atlas core addon.
2. Install Atlas Class Order Halls for the same WoW client.
3. Enable both addons in the character selection screen's AddOns list.
4. Open Atlas with `/atlas` and select a class order hall map.

For manual installation, extract the addon into the `Interface/AddOns`
directory of the WoW client you use. Preserve the addon folder structure
and avoid an extra wrapper folder.

## About This Plugin

This plugin supplies class order hall map content for the Atlas browser;
it does not provide a separate map interface.

This repository contains the Atlas Class Order Halls plugin, not the Atlas core
or the Atlas Legion instance map module.
